# 创意构思

## 适用场景

当用户说"我想做点什么"、"给我一个项目 idea"、"我好无聊"、"我该做什么"、"给我点灵感"，或任何表示"我有工具但没有方向"的变体时使用。适用于代码、艺术、硬件、写作、工具以及任何可被创造的事物。

通过创意约束来生成项目创意。约束 + 方向 = 创造力。

## 工作原理

1. **挑选一个约束** — 随机选择，或根据用户的领域/心情匹配
2. **宽泛解读** — 编程提示可以变成硬件项目，艺术提示可以变成 CLI 工具
3. **生成 3 个具体的项目创意**，满足该约束条件
4. **如果用户选定一个，就动手做** — 创建项目、写代码、交付

## 规则

每条提示都尽可能宽泛地解读。"这算不算 X？" → 算。提示提供方向与轻度约束。两者缺一，便无创造力可言。

## 约束库

### 面向开发者

**解决你自己的痛点：**
做出你这周希望存在的工具。50 行以内。今天就交付。

**自动化那些烦人的事：**
你工作流中最繁琐的部分是什么？用脚本干掉它。花两小时解决一个每天浪费你五分钟的问题。

**那个应该存在的 CLI 工具：**
想一个你曾经希望能敲出来的命令。`git 撤销我刚做的事`。`docker 为什么坏了`。`npm 解释一下你自己`。现在把它做出来。

**除了胶水别无新物：**
完全用现有的 API、库和数据集拼出一样东西。唯一原创的贡献就是你如何把它们连接起来。

**弗兰肯斯坦周：**
拿一个做 X 的东西，让它去做 Y。一个能播放音乐的 git 仓库。一个能生成诗歌的 Dockerfile。一个会发赞美消息的定时任务。

**做减法：**
在一个代码库崩掉之前，你能删掉多少东西？把一个工具削减到它的最小可用功能。删到只剩本质为止。

**高概念，低投入：**
一个深刻的想法，懒散地执行。概念应该出彩，实现应该一个下午就能完成。如果耗时更长，说明你想太多了。

### 面向创作者与艺术家

**明目张胆地抄袭：**
选一个你欣赏的东西 — 一个工具、一件艺术品、一个界面。从头复刻它。学习的收获就在于你的版本和原作之间的差距。

**一百万个什么东西：**
一百万既很多又没那么多。一百万个像素是一张 1MB 的照片。一百万次 API 调用不过是一个普通的星期二。一百万件任何东西到了规模就变得有趣了。

**做一个会消亡的东西：**
一个每天失去一个功能的网站。一个会遗忘的聊天机器人。一个通向虚无的倒计时。一次关于腐烂、消亡或放手的练习。

**做很多数学：**
生成几何、shader 极简竞赛、数学艺术、计算折纸。是时候重新认识一下反正弦是什么了。

### 面向所有人

**文字是通用界面：**
做一个文字是唯一界面的东西。没有按钮，没有图形，只有文字进、文字出。文字几乎可以从任何东西里进去再出来。

**从笑点开始倒推：**
想一句会很好笑的句子。从那里倒推把它变成现实。"我教会了我的恒温器对我 PUA" → 现在就把它做出来。

**充满敌意的 UI：**
做一个故意让人用着难受的东西。一个需要满足 47 个条件的密码输入框。一个标签全在撒谎的表单。一个会评判你命令的 CLI。

**再来一次：**
回想一个旧项目。从头再做一遍。不许看原来的版本。看看你思考的方式发生了什么变化。

参见 `references/full-prompt-library.md` 获取 30+ 个额外的约束，涵盖沟通、规模、哲学、变形等领域。

## 约束与用户匹配指南

| 用户说法 | 从中选择 |
|-----------|-----------|
| "我想做点什么"（没有方向） | 随机 — 任意约束 |
| "我在学 [语言]" | 明目张胆地抄袭、自动化那些烦人的事 |
| "我想要点奇怪的" | 充满敌意的 UI、弗兰肯斯坦周、从笑点开始倒推 |
| "我想要点有用的" | 解决你自己的痛点、那个应该存在的 CLI 工具、自动化那些烦人的事 |
| "我想要点好看的" | 做很多数学、一百万个什么东西 |
| "我 burnout 了" | 高概念低投入、做一个会消亡的东西 |
| "周末项目" | 除了胶水别无新物、从笑点开始倒推 |
| "我想要一个挑战" | 一百万个什么东西、做减法、再来一次 |

## 输出格式

```
## 约束：[名称]
> [一句话描述约束]

### 创意

1. **[一句话标题]**
   [2-3 句话：你会做什么以及为什么有趣]
   ⏱ [周末 / 周 / 月] • 🔧 [技术栈]

2. **[一句话标题]**
   [2-3 句话]
   ⏱ ... • 🔧 ...

3. **[一句话标题]**
   [2-3 句话]
   ⏱ ... • 🔧 ...
```

## 示例

```
## 约束：那个应该存在的 CLI 工具
> 想一个你曾经希望能敲出来的命令。现在把它做出来。

### 创意

1. **`git whatsup` — 展示你不在的时候发生了什么**
   对比你最后一次活跃提交和 HEAD，总结发生了什么变化、
   谁提交了什么、合并了哪些 PR。就像你仓库里的晨间站会。
   ⏱ 周末 • 🔧 Python, GitPython, click

2. **`explain 503` — 人类可读的 HTTP 状态码**
   传入任意状态码或错误信息，返回通俗英文解释
   以及常见原因和修复方法。数据来源是精选数据库，不是 LLM。
   ⏱ 周末 • 🔧 Rust 或 Go, 静态数据集

3. **`deps why <package>` — 它为什么在我的依赖树里**
   沿着传递依赖回溯到引入它的直接依赖。
   一个命令回答"为什么我装了 47 个 lodash"。
   ⏱ 周末 • 🔧 Node.js, npm/yarn lockfile 解析
```

用户选定一个之后，就开始动手 — 创建项目、写代码、迭代。
